# Security

## Reporting a vulnerability

If you believe you have found a security issue in **Facthory the product** (not a typo in these guides), please report it privately through your Facthory account team or the security contact published on [facthory.com](https://facthory.com). Do not open a public GitHub issue with exploit details.

## This repository

`FACTHORYAI/guides` is a documentation mirror. It should never contain:

- Secrets, tokens, or credentials
- Private customer data
- Internal infrastructure details

If you accidentally find sensitive material in a guide or commit history, open a private report and we will remediate quickly.

## Documentation feedback vs security

| Topic | Channel |
| --- | --- |
| Unclear how-to, missing step, typo | [Documentation feedback issue](https://github.com/FACTHORYAI/guides/issues/new?template=doc-feedback.yml) |
| Suspected product vulnerability | Private security report (not a public issue) |
