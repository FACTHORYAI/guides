# Facthory Guides

Practical how-to guides for [Facthory](https://facthory.com) — the operational intelligence platform that helps teams capture knowledge, collaborate with multiplayer AI agents, and run grounded work across documents, video, email, and everyday operations.

**Canonical documentation site:** [facthory.com/resource/documentation](https://facthory.com/resource/documentation/)

This GitHub repository is a public, browseable Markdown mirror of our published customer guides. Use it to read offline, deep-link from issues, or skim the catalog. The living product experience (search, navigation, SEO) lives on the website.

## How these guides are maintained

| Role | System |
| --- | --- |
| Editorial source of truth | Notion (Facthory Documentation) |
| Product docs experience | [facthory.com/resource/documentation](https://facthory.com/resource/documentation/) |
| This repository | Generated Markdown mirror (read-only for content) |

**Do not edit guide bodies in pull requests.** Content changes are applied in Notion, published, then mirrored here after our production release process.

## Feedback

Found a typo, gap, or unclear step?

1. Open a **[Documentation feedback](https://github.com/FACTHORYAI/guides/issues/new?template=doc-feedback.yml)** issue (preferred).
2. Include the guide slug or path (for example `docs/agents/start-an-agent-conversation.md`) and the canonical URL on facthory.com when you have it.
3. We will update Notion; the next mirror refresh updates this repo.

Pull requests that only fix typos may be closed with a pointer to Issues — maintainers land accepted feedback in the editorial system of record.

See [CONTRIBUTING.md](CONTRIBUTING.md).
